# Literalura

Aplicación en Java con Spring Boot que consume la API Gutendex para buscar libros y guardarlos en una base de datos PostgreSQL.

## Funciones

- Buscar libros por título
- Listar libros registrados
- Listar autores
- Buscar libros por idioma

## Tecnologías

- Java
- Spring Boot
- PostgreSQL
- Hibernate
- Gutendex API
